# ReUnityHandler & WebMIS Importer

Веб-приложение и браузерное расширение для медицинских врачей. Проект предназначен для удобного управления статусами заполнения профилей и автоматизированного импорта данных из системы ReUnityHandler напрямую в формы ВебМИС.

## Технологический стек

### Backend
* **FastAPI** — высокопроизводительный асинхронный веб-фреймворк.
* **SQLAlchemy 2.0** (с драйвером `asyncpg`) — ORM для асинхронной работы с базой данных.
* **PostgreSQL** — основная реляционная база данных.
* **Alembic** — система контроля версий структуры БД (миграции).
* **Jinja2** — шаблонизатор для рендеринга HTML.

### Frontend / Extension
* **Vanilla JavaScript**
* **HTML / CSS**
* **Manifest V3** (Chrome Extension API)

## Основной функционал

* **Заполнение медицинских документов:** Создание, редактирование и выгрузка медицинского документа врачебной комиссии медицинской реабилитации одновременно несколькими врачами.
* **Мониторинг статусов:** Отслеживание и управление статусами завершения работы врачей на бэкенде.
* **Автоматизация переноса данных:** Браузерное расширение извлекает структурированные данные из ReUnityHandler и автоматически заполняет поля на страницах ВебМИС.
* **Изолированная среда:** Быстрое развертывание серверной части через Docker.

## Быстрый старт (Локальное демо)

Проект разделен на две части: серверную (бэкенд) и клиентскую (браузерное расширение).

### 1. Запуск серверной части (Backend)

Для запуска потребуется установленный Docker и Docker Compose.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/ReUnityHandler-Demo.git
   cd ReUnityHandler-Demo
   ```

2. Соберите и запустите контейнеры в фоновом режиме:
   ```bash
   docker-compose up -d --build
   ```

После выполнения этих шагов бэкенд будет доступен по адресу: `http://localhost:8000`
Данные для входа в режиме администратора:
* **Логин:** admin
* **Пароль:** 1234

### 2. Права доступа

Для взаимодействия с окружением существует два типа ролей: **администратор и врачи**. Ниже будут приведены различия в доступе к функциям у этих ролей.

1. **Администратор**

Роль администратора предназначена для администрирования базы данных через интерфейс веб-сервиса.

**Права:**
* Добавление учётных записей;
* Редактирование данных, изменение статуса активности и отображения учётных записей;
* Добавление, редактирование и удаление **любых** пациентов;
* Добавление, редактирование и удаление **любых** медицинских записей, а так же изменение их статуса завершённости.

2. **Врачи**

Существует несколько разновидностей роли "врач": рефлексотерапевт, физиотерапевт, терапевт/врач фрм, невролог/врач фрм, психотерапевт. В правах по взаимедойствию с окружением все они **одинаковы**. Различные подтипы роли "врач" созданы для **отображения статуса заполнения** документа конкретным врачом. 

**Права:**
* Добавление, редактирование и удаление медицинских записей, **созданных активным врачом**;
* Изменение статуса завершённости медицинской записи или раздела активного врача;
* Добавление пациентов;
* Редактирование и удаление пациентов, **созданных активным врачом**.

### 3. Установка браузерного расширения

1. Откройте браузер на базе Chromium (Google Chrome, Microsoft Edge, Яндекс.Браузер).
2. Перейдите по адресу `chrome://extensions/`.
3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked).
5. Выберите папку `browser_extension` из склонированного репозитория.

> **Примечание:** Расширение настроено на работу с рабочим контуром ВебМИС. Для тестирования инъекции скриптов убедитесь, что целевой URL совпадает с доступами в `manifest.json`. Без доступа к ВебМИС, браузерное расширение носит исключительно демонстрационную функцию.
